# Product

<!-- impeccable:product-schema 1 -->

## Platform

web

## Users

VisualGrilling users review projects with Codex or Claude Code through a local browser map. The boards Hub serves users of local Windows and Chrome who need to return to boards across projects.

## Product Purpose

Keep questions, answers, discussions and review findings on persistent maps. The Hub adds a registry, navigation and explicit Codex Play/Stop controls without confusing board completion, server availability and agent attachment.

## Operating Context

The map runtime uses Node built-ins and vanilla browser JavaScript. The Hub uses a local Windows component and a Chrome extension. Closing a tab does not stop a board. Active boards are all unfinished boards, including stopped boards.

## Capabilities and Constraints

The Hub preserves unavailable registry entries, checks board identity during path recovery, and labels cached observations as stale. Current questions with status ok are closed; current open, weak, gap and verify questions are open. Obsolete cards and non-question cards do not count. Production Chrome Store publication and real reboot acceptance are external verification requirements, not completed product claims.

## Brand Commitments

The new extension inherits the existing map interface identity. User-facing initial Hub labels are Russian; developer documentation is English.
