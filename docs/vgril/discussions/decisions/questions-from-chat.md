# Вопросы из обсуждения

Согласованные требования к будущему поведению, не описание реализованной функции.

- Все содержательные вопросы модели, требующие ответа пользователя, автоматически появляются на схеме.
- Агент ищет подходящий родительский вопрос по всей карте; если такого нет, добавляет к корню.
- Перед созданием проверяет существующие карточки: при совпадении ссылается на имеющуюся и учитывает её ответ.
- Один ответ пользователя записывается в несколько соответствующих карточек. Каждая оценивается отдельно и закрывается только при достаточном ответе.
- В чате остаются текст вопросов и ссылки на карточки.
- Правила действуют в обсуждениях вопроса, проекта и идеи с учётом контекста.

Все необходимые вопросы выдаются без искусственной квоты. Карточки, утратившие актуальность и имеющие ответы, сохраняются как устаревшие. Независимый переключатель «Устаревшие» добавляет все исторические карточки к результату статусных фильтров или скрывает их. По умолчанию устаревшие скрыты; выбор переключателя запоминается отдельно для каждой карты. При выключенном переключателе устаревший предок актуального видимого вопроса остаётся приглушённым только как контекст. Это явное исключение из скрытия, сохраняющее связность дерева. Текущий apply discuss сохраняет reply и оценку текущей карточки, но не создаёт вопросы. Существующее перечитывание умеет учитывать ответы других карточек; новое требование распространяет это на обсуждение.
