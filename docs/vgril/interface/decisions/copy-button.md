# Расположение кнопки копирования

Согласованное целевое поведение для работы мышью:

- Кнопка появляется при наведении на текстовый блок и находится внутри него справа сверху.
- Правило применяется к вопросу и сообщениям чата. Ответ и вердикт визуально разделяются на самостоятельные блоки, каждый со своей кнопкой копирования.
- Каждая кнопка копирует текст своего блока.
- Клавиатура, сочетания клавиш и сенсорный экран отложены в отдельное обсуждение; не возвращаться к ним в этой карте.
- Проверку удобства пользователь берёт на себя. Результат пока не подтверждён.

Это решение о будущем интерфейсе: текущий skills/grill/ui.html пока выводит текстовые кнопки после текста. Реализация в рамках гриллинга не запрошена. Ранее docs/specs/grill-ux-completeness.md уже требовал отдельного копирования каждого типа текста; новое размещение совместимо с этим требованием.

Дополнительно согласовано:

- Подтверждение успешного копирования показывается анимацией на самой кнопке (nzcktbnk). Конкретный рисунок и длительность анимации не выбраны.
- Новое размещение применяется ко всем отдельным текстам, включая историю вердиктов и объединённые ответы (nc2bo4fo).
- Экспорт составляет исключение: его кнопка остаётся под полем Markdown (nc2bo4fo).

Известных открытых вопросов в рамках размещения для мыши больше нет. Проверка удобства остаётся неподтверждённой и поручена пользователю.
